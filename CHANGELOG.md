# Changelog

Todos los cambios notables de este proyecto se documentan en este archivo.

El formato sigue [Keep a Changelog](https://keepachangelog.com/es/1.1.0/),
y este proyecto adhiere a [Semantic Versioning](https://semver.org/lang/es/).

## [Sin publicar]

## [1.1.0] - 2026-11-13

### Añadido

- Región de contenido compartida: los bloques raíz pueden ocupar el ancho de la ventana sin alterar los anchos, márgenes ni espaciados predeterminados del tema.
- Punto compartido de overlays para contribuciones opcionales y marca de previsualización sin acciones públicas.


## [1.0.1] - 2026-11-12

### Corregido

- Las vistas respetan el layout de página seleccionado y las traducciones del idioma y mercado solicitados.
- La dependencia mínima de core pasa a `^1.1` por las APIs compartidas que utiliza este paquete.

## [1.0.0] - 2026-11-05

### Añadido

- Primera versión pública.
- `dbravoan/dbcms-theme-db-sunset` es un tema público (`dbcms-theme`). Identifier: `db-sunset`. Estética glassmorphism moderna sobre fondo obsidiana con degradados atardecer, paneles traslúcidos y acentos rosa/ámbar.
